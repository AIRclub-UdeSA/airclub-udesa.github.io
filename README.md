# AIR Club UdeSA · sitio raíz de GitHub Pages

Este repositorio publica la raíz `https://airclub-udesa.github.io/` y los archivos que deben vivir en el nivel superior del host.

## Contenido

- `index.html`: redirige al sitio público del club.
- `robots.txt`: permite el rastreo y declara el sitemap del Challenge JAR 2026.

El perfil público y los archivos comunitarios compartidos de la organización viven en [`AIRclub-UdeSA/.github`](https://github.com/AIRclub-UdeSA/.github). El sitio y la documentación del desafío viven en [`AIRclub-UdeSA/jar_site`](https://github.com/AIRclub-UdeSA/jar_site).

## Publicación

GitHub Pages publica la rama `main` desde la raíz del repositorio.
